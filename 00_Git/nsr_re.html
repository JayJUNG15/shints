1. 프로젝트 개요

프로젝트명

NSR 제품기획·디자인 경력직 채용공고

채용 포지션

  • 포지션: 제품기획 및 디자인
  • 채용 구분: 경력직
  • 필요 경력: 관련 경력 3년 이상
  • 담당 분야: 사이클링웨어 및 기능성 스포츠웨어

채용공고의 목적

단순히 기존 제품을 반복해서 디자인하는 사람이 아니라, 시장과 라이더를 이해하고 NSR의 시즌 상품 전략부터 디자인·샘플·생산 협업까지 연결할 실무자를 모집한다.

지원자에게 전달할 핵심 인상

  • 기능성 스포츠웨어를 실제 제품으로 완성하는 브랜드
  • 라이딩 문화와 시장을 가까이서 관찰하는 조직
  • 기존 자산 위에 다음 제품과 브랜드 방향을 만들어가는 전환기
  • 디자이너가 제품 전략과 결과물에 실질적으로 기여할 수 있는 환경

외부 채용공고에서 회사를 ‘스타트업’으로 직접 표현하지 않는다. 실제 기업 성격과 다른 인상을 줄 수 있으므로, 시각적 민첩성과 도전성만 가져온다.

카피 변경 이유

초안의 NEVER STOP RESTARTING.은 브랜드 슬로건과의 연결성은 있으나, 영어 표현이 다소 인위적이고 ‘계속 재시작하는 회사’라는 불안정한 인상을 줄 수 있다. 따라서 공식 슬로건 NEVER STOP RIDING.은 브랜드 메시지로 유지하고, 채용 메시지는 지원자의 역할이 선명한 DESIGN THE NEXT RIDE.로 구분한다.

메시지 위계

  1. DESIGN THE NEXT RIDE. — 채용공고의 메인 메시지
  2. 제품기획 및 디자인 경력직 채용 — 포지션 설명
  3. NSR의 다음 제품과 라이딩 경험을 함께 설계합니다. — 역할 의미
  4. NEVER STOP RIDING. — 브랜드 서명

3. 전체 디자인 방향

원하는 인상

  • Performance Sports Brand
  • Movement & Speed
  • Product Creation
  • Functional Precision
  • Young but Professional
  • Bold, Clear, Focused

피해야 할 인상

  • 제조업 인사팀이 만든 표 중심 공고
  • 취업포털 기본 템플릿 또는 관공서 문서
  • 자전거 사진과 속도 효과를 과도하게 사용한 동호회 홍보물
  • 실제 조직과 다른 ‘스타트업 회사’ 연출
  • 의미 없는 영문 문구와 장식용 아이콘의 남발
  • 경쟁 브랜드의 컬러·그래픽·촬영 구도를 그대로 모방한 결과물
  • 기능성 의류의 전문성보다 패션 화보만 강조한 결과물

핵심 디자인 원칙

  1. 한 화면 또는 한 섹션에는 핵심 메시지 하나만 강조한다.
  2. 큰 타이포그래피와 넓은 여백으로 속도감과 자신감을 표현한다.
  3. 긴 설명보다 짧은 문장·숫자·키워드·카드 구조를 사용한다.
  4. 라이딩 이미지와 제품 개발 이미지를 균형 있게 사용한다.
  5. 모든 그래픽은 장식이 아니라 정보의 흐름과 방향을 보여주는 용도로 쓴다.
  6. 모바일 화면에서도 제목·직무·지원 조건이 즉시 읽혀야 한다.

그래픽 사용 원칙

  • 그래픽 요소는 2~3종 이내로 통일한다.
  • 기울기·모션 블러·사선은 핵심 장면에서만 제한적으로 사용한다.
  • 자전거 바퀴, 체인, 속도계 아이콘을 반복 장식으로 사용하지 않는다.
  • 실제 제품 구조와 혼동될 수 있는 가상의 봉제선·절개선은 넣지 않는다.

5. 이미지 가이드

이미지 우선순위

  1. 실제 NSR 제품 개발 과정: 작업지, 스케치, 원단, 컬러칩, 부자재, 샘플
  2. 실제 NSR 제품의 기능 디테일: 원단 조직, 지퍼, 포켓, 패드, 봉제선, 리플렉티브
  3. 실제 NSR 제품을 착용한 라이더의 주행 장면
  4. 도로·코스·도시의 추상적 장면

권장 촬영·선정 기준

  • 제품 로고와 디테일이 정확히 보이는 고해상도 이미지
  • 라이더의 진행 방향과 타이포그래피의 흐름이 일치하는 이미지
  • 지나치게 광고 포즈를 취한 정면 인물보다 자연스러운 주행 장면
  • 다양한 연령을 보여주더라도 전체 톤은 현대적으로 통일
  • 배경이 복잡한 사진은 텍스트를 직접 올리지 않고 별도 영역을 확보

금지사항

  • 경쟁사 제품·로고·매장 이미지 사용 금지
  • 저작권 또는 초상권이 확인되지 않은 이미지 사용 금지
  • 실제 NSR 제품처럼 보이는 AI 생성 제품 클로즈업 사용 금지
  • 존재하지 않는 봉제 구조·원단·지퍼·그래픽을 실제 상품처럼 표현하지 않음
  • 과거 이미지 사용 시 현재 판매 제품으로 오해하지 않도록 확인

  • Black: 25~30%
  • NSR Red: 10% 이내

레드 사용 위치

  • 메인 카피의 핵심 단어
  • 포지션명
  • 섹션 번호
  • 선·화살표·페이지 진행 표시
  • 지원 CTA

레드를 전체 배경에 반복 사용하지 않는다. 한 페이지에서 가장 중요한 정보 한 곳을 표시하는 색으로 사용한다.

7. 타이포그래피 가이드

권장 서체

  • 영문 헤드라인: Archivo Bold/Black 또는 승인된 Condensed Sans Serif
  • 한글 헤드라인·본문: Pretendard
  • 대체 서체: SUIT, Noto Sans KR

유료 서체는 회사가 보유한 라이선스를 확인한 뒤 사용한다. 여러 서체를 혼용하지 않고 영문 1종, 한글 1종으로 제한한다.

권장 크기 — 가로 1,000px 마스터 기준

구분 권장 크기 굵기 원칙
메인 영문 카피 88~120px Black 2~3줄 이내
한글 메인 메시지 38~48px Bold 핵심 역할을 한 문장으로 표현
섹션 타이틀 32~40px Bold 섹션당 하나
카드 키워드 20~26px Bold 영문 키워드 중심

보조 정보 15~18px Regular 대비를 충분히 확보

조판 원칙

  • 영문 헤드라인은 크게, 한글은 의미를 설명하는 역할로 배치한다.
  • 본문 한 줄은 모바일 기준 25~35자 내외를 권장한다.
  • 영문 전체 대문자 본문을 길게 사용하지 않는다.
  • 중앙 정렬은 HERO와 마지막 CTA에만 제한적으로 사용한다.
  • 행간과 섹션 여백을 충분히 확보해 정보 밀도를 낮춘다.

10. 제작 규격 및 산출물

기본 마스터

  • 세로형 상세페이지 마스터: 가로 1,000px
  • 권장 전체 길이: 약 9,000~12,000px
  • 단일 열 구조로 제작
  • 모바일 화면에서 텍스트 크기와 줄바꿈을 우선 검토
  • 컬러 모드: RGB / sRGB

필수 산출물

  1. 세로형 상세페이지 원본 및 최종 이미지
  2. 채용 카드형 이미지 1080 × 1350px, 6~8장
  3. 채용 썸네일 1080 × 1080px, 1~2안
  4. 수정 가능한 원본 파일: Figma 또는 Illustrator
  5. 사용 이미지·폰트·링크 목록
  6. 최종 카피가 텍스트로 분리된 파일

카드형 이미지 권장 구성

카드 내용
1 HERO / 포지션명
2 NSR 브랜드와 채용 메시지
3 핵심 업무
4 필수 자격
5 우대 경험
6 일하는 방식
7 근무조건·전형
8 지원 CTA

납품 원칙

  • 텍스트는 모두 편집 가능한 상태로 제공한다.
  • 링크 이미지 사용 시 누락 없이 패키징한다.
  • 플랫폼별 용량 제한에 맞춘 최종 JPG/PNG를 별도로 제공한다.
  • PC·모바일에서 글자 뭉개짐과 줄바꿈을 각각 검수한다.

12. 최종 검수 체크리스트

메시지

  • 첫 화면에서 NSR·채용 포지션·경력직 여부가 바로 보이는가
  • 지원자가 맡게 될 역할이 일반 그래픽디자인과 구분되는가
  • 제품기획부터 샘플·생산 협업까지의 범위가 드러나는가
  • 확인되지 않은 회사 문화·복지·성과를 과장하지 않았는가
  • 필수 자격과 우대사항이 명확히 구분되는가

디자인

  • 일반 제조업 채용공고처럼 보이지 않는가
  • 라이딩 브랜드의 속도감과 기능성 의류의 정밀함이 함께 보이는가
  • 레드가 강조용으로 절제되어 있는가
  • 모바일에서 본문과 지원조건이 충분히 읽히는가
  • 한 섹션에 메시지가 여러 개 경쟁하지 않는가

이미지·권리

  • 경쟁사 제품이나 로고가 노출되지 않는가
  • 사용 이미지의 저작권·초상권을 확인했는가
  • 실제 NSR 제품과 다른 AI 생성 디테일이 없는가
  • 과거 제품을 현재 제품처럼 오해하게 만들지 않는가

지원 전환

  • 근무지·고용 형태·전형·마감일·지원방법이 모두 확정됐는가
  • 포트폴리오 제출 기준이 명확한가
  • CTA 링크와 QR 코드가 실제로 작동하는가
  • 채용 플랫폼 업로드 후 PC·모바일 화면을 다시 확인했는가
